# Артель — сайт компании

Главная страница регионального центра строительных исследований «Артель».

## Локальный запуск

```sh
pnpm install
pnpm dev
```

## Публикация

Сайт собирается как статические файлы и публикуется на GitHub Pages по адресу:
`https://huyaka10.github.io/artel/`

Публикация запускается автоматически при отправке изменений в ветку `main`.
